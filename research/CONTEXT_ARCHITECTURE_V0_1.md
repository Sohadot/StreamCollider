## Generalization test

Reference Case 001 must pass first.

If it passes, the second proving case should intentionally come from advanced silicon/chiplets rather than another quantum example. If the method works in both domains, the thesis has cross-domain strength. If it works only in quantum–HPC, StreamCollider should narrow rather than pretend universality.
