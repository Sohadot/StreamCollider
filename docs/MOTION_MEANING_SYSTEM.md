# Motion Meaning System v0.1

Motion is permitted only when it conveys system meaning.

## Allowed motion

### Stream pulse
A short directional pulse along an SVG path.
Meaning: a computational stream crossing a boundary.

### Boundary activation
A governance divider increases contrast when selected.
Meaning: this boundary is the current unit of analysis.

### Unknown reveal
Unknown markers unfold from a boundary.
Meaning: evidence ends before authority/state is fully resolved.

### Context progression
Layers reveal in sequence when entering the Advanced Compute section.
Meaning: increasing modularity/heterogeneity, not historical inevitability.

## Disallowed motion

- endless decorative particles
- random parallax
- cursor-following glow
- autoplay 3D
- physics collisions used as metaphor without analytical content
- animation that blocks reading

## Reduced motion

When `prefers-reduced-motion: reduce` is active:
- path pulses are disabled
- transitions become near-instant
- no meaning is lost
