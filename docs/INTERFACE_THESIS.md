# StreamCollider Interface Thesis v0.1

## Interface role

The interface must embody the thesis rather than decorate it.

> **StreamCollider studies what happens when independently governed compute streams become mutually consequential.**

The public surface behaves as a **Boundary Field**: a legible environment in which domains, streams, authority transitions, evidence states and unresolved boundaries are visible as relationships.

## Experience principles

1. **Concept first** — visual structure must explain the category.
2. **Evidence before spectacle** — every strong claim must have an evidence path.
3. **Light, mineral, technical** — no generic black/neon quantum aesthetic.
4. **Motion has semantics** — movement denotes transfer, uncertainty, state change or boundary activation.
5. **The field is the navigation grammar** — domains and boundaries are primary; feature cards are secondary.
6. **Advanced chips are context, not yet a proving case** — chiplets, fabrics and photonics appear in the context architecture without being misclassified as Stream Collisions.
7. **No visual overclaim** — visual prominence must not imply evidentiary closure.

## First public experience

The homepage opens with five analytical domains:
- Advanced Silicon
- Fabrics / Memory
- HPC / Classical
- Quantum Resource
- Distributed Compute

A central evidence boundary connects them. Interaction reveals:
- who governs each side,
- what crosses,
- what is known,
- what remains unknown,
- whether the case is proved or contextual.

## Semantic visual states

- **Known** — solid edge / stable label
- **Unknown** — open marker / incomplete edge
- **Assumed** — dotted treatment
- **Evidence boundary** — broken rule
- **Governance boundary** — stronger structural divider
- **Context only** — low-emphasis chip / `context` badge

## Prohibited interface patterns

- black + neon cyberpunk
- glowing quantum sphere
- decorative particle storms
- generic SaaS hero
- fake live telemetry
- meaningless glassmorphism
- decorative 3D without explanatory value
- unbounded animation
