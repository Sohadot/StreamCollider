Unit of Analysis

Governance Boundaries

A physical edge is not automatically a governance boundary. The relevant question is where authority becomes materially non-singular.

Authority dimensions

  • Scheduling
  • Execution
  • Resource
  • State
  • Firmware / control
  • Calibration / maintenance
  • Telemetry / measurement
  • Recovery
  • Policy / security
  • Accounting / proof

Harsh test

What can neither party govern independently once the interaction begins?

If there is no meaningful answer, the case is unlikely to qualify as a Stream Collision.
